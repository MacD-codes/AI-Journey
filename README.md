# About this Course

This repository is based on the Udemy course:

### **AI Engineer Core Track: LLM Engineering, RAG, QLoRA, Agents**

The course is designed to provide practical AI Engineering skills by combining Python programming, Natural Language Processing, Large Language Models, LangChain, Vector Databases, Retrieval-Augmented Generation (RAG), APIs, and AI application development into one structured learning path.

Unlike traditional theory-heavy learning, this course focuses on hands-on implementation and real-world AI workflows used in modern AI-driven applications.

The course covers important AI Engineering concepts including:

- Artificial Intelligence fundamentals
- Python programming for AI
- Natural Language Processing (NLP)
- Large Language Models (LLMs)
- Transformers and Hugging Face
- LangChain
- Vector Databases using Pinecone
- Retrieval-Augmented Generation (RAG)
- AI APIs and integrations
- Speech Recognition with Python
- Building AI-powered applications
